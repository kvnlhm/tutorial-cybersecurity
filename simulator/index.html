Percobaan pertama, tanpa instal alat

  1. Pilih Belajar dengan petunjuk. Mulai dari misi pertama.
  2. Baca tugas. Pada terminal virtual, ketik pwd, lalu tekan Enter. Itu perintah untuk melihat lokasi.
  3. Ketik ls untuk daftar berkas. Baca hasil sebelum mengetik perintah berikutnya.
  4. Jika bingung, buka petunjuk satu per satu. Kesalahan tidak mengurangi nyawa atau menghapus hasil misi lain.
  5. Setelah selesai, jelaskan alasan tindakan Anda di catatan. Uji lagi dengan kasus berbeda.

Terminal ini hanya mengolah berkas virtual. Jangan memasukkan password, nama pelanggan asli, atau perintah dari internet. Data di semua misi memang dibuat untuk latihan.

Progres mencoba tersimpan di browser perangkat ini. Mode privat atau membuka lokasi file berbeda dapat menghilangkannya. Unduh catatan sebelum menutup jika ingin menyimpan bukti.

Ulangi misi ini?

Hasil, petunjuk, dan catatan misi pada mode saat ini akan dihapus. Misi lain dan mode lainnya tetap tersimpan. Unduh catatan dahulu bila perlu.
